# 見る君 機器選定書（2026年10月時点・調査版）

店頭のパソコンはお客様のものを使い、当社は **モニター・USBカメラ・スタンド・ケーブル類** を提供する前提での選定です。

## 1. ソフトの仕組みから決まる条件

| 項目 | 条件 | 理由 |
|---|---|---|
| カメラの画角 | **横 約60〜75°**（対角 70〜80°前後） | 顔検出には顔が約50px以上映る必要がある。横70°・1280px なら 2m 先の顔（幅15cm）は約69px で余裕あり。広角（横100°以上）は顔が小さくなり検出できなくなる |
| カメラの解像度 | 1280×720 以上・30fps、UVC 対応（ドライバ不要） | ブラウザで 1280×720 を取り込んで解析する |
| 逆光・暗さ | 逆光補正（HDR/WDR）があると望ましい | 入口のガラス越しの外光、夕方以降の暗さで顔が潰れる |
| モニター | 屋内用・**連続稼働の定格があるもの**、非光沢、有機EL（OLED）は不可 | 1日10〜16時間の表示。同じ画面の長時間表示で焼き付くため OLED は避ける |
| 設置高さ | カメラ（＝画面上端）が **床から約1.3〜1.6m** | 顔とカメラの高さを近づけると向きの判定が安定する |

## 2. お客様のパソコンの条件

| 項目 | 必要 | 推奨 |
|---|---|---|
| OS | Windows 10/11 または macOS | Windows 11 |
| ブラウザ | Chrome / Edge（最新版） | Chrome |
| CPU | 4コア以上 | 第8世代 Core i3 / Celeron N100 以上 |
| メモリ | 4GB 以上 | 8GB 以上 |
| 端子 | HDMI 出力 1、USB-A 1 | — |
| その他 | 営業中ずっとサイネージ専用で使える（レジ・事務と兼用しない） | スリープ無効、起動時に自動で `/player` を全画面表示 |

**判定は `/check`（動作チェック画面）で行います。** 営業時にお客様のパソコンで開くと、ブラウザ・カメラ・顔検出の速さ・顔の映り方を自動で点検し、合格／不合格を表示します。

## 4. カメラの比較

| 機種 | 横の画角（推定） | 逆光補正 | 価格の目安 | 評価 |
|---|---|---|---|---|
| **Logicool C920s** | 約70° | なし（自動露出補正のみ） | 約8千円 | **標準採用**。実績が多く入手しやすい |
| Logicool C922n | 約70° | なし | 約1.1万円 | C920s と同等で割高 |
| Logicool BRIO 300 | 約63° | なし | 約6〜8千円 | USB-C のみ（変換が必要）。一部の色は品薄 |
| Logicool BRIO 100 | 約52° | なし | 約4.5〜5千円 | 安いが画角が狭い（2m先で幅約2m） |
| エレコム UCAM-C820ABBK | 約69° | 記載なし | 約5千円 | 格安候補。Mac 公式非対応 |
| Logicool BRIO 4K | 約58/70/82°（切替） | **HDRあり** | 約2.8万円〜 | 逆光が強い店舗向けの選択肢。HDR の効果は限定的との評価もある |

- 調べた範囲では、条件に合う**マイクなし**の機種は見つかりませんでした。見る君はマイクを使いません（ブラウザで音声を取得しない設定）。
- 逆光対策は機材より設置で解決する方が効果的です（カメラを窓に向けない、入口の内側から店外に向けない、手前に照明を足す）。

## 5. 設置の基本

1. モニターは入口付近の店内に、通路を歩く人の正面を向くように置く
2. カメラは画面上端の中央に取り付け、やや下向きにする
3. 画面上端の高さを床から 1.3〜1.6m に合わせる（43型は画面の高さが約54cm）
4. パソコンはスタンドの棚か近くに置き、USB は延長なし（直挿し）が理想
5. 設置後、サイネージ画面で `D` → 「いまの顔の向きを『画面を見ている』として補正」
6. 店頭に「AIカメラで人数を計測しています（映像は保存しません）」の掲示を出す

## 6. 発注前に実機で確かめること

- [ ] C920s：逆光（ガラス入口を背にした人）で顔が検出されるか、自動露出が安定するか
- [ ] 0.5 / 1 / 2 / 3m で顔の映る大きさ（`/check` の「この位置で判定」）
- [ ] Chrome で 1280×720 が取れるか、暗い時間帯に 10fps を保てるか
- [ ] オートフォーカスの迷い（ピントの行ったり来たり）が判定に影響しないか
- [ ] USB延長ケーブル使用時、数日間つなぎっぱなしで切断が起きないか
- [ ] PN-HW432：停電復帰時に自動で電源が入るか、信号なしで勝手にスリープしないか
- [ ] 100-PL008：43型取り付け時の画面上端の高さ
