# 見る君（プロトタイプ / 第0段階）

飲食店向けAIサイネージの試作品です。ポスターを表示しながら USB カメラで「何人が前を通り、何人が何秒見たか」を計測し、管理画面で効果を確認できます。

- **アカウント・サーバー不要**：データはすべてブラウザ内（IndexedDB）に保存されます
- **映像は保存・送信しない**：顔の検出と向きの推定はパソコンの中（ブラウザ内の MediaPipe）で行い、残すのは1分ごとの人数と秒数だけです

## 起動

```bash
cd miru-kun
npm install      # MediaPipe の WASM が public/mediapipe にコピーされます
npm run dev      # http://localhost:3000
```

| 画面 | URL | 用途 |
|---|---|---|
| トップ | `/` | 入口 |
| サイネージ画面 | `/player` | 店頭モニターに全画面表示。`D` で計測状況、`F` で全画面 |
| ダッシュボード | `/admin` | 通行人数・注視人数・注視率・平均注視時間、時間帯別、ポスター別 |
| ポスター | `/admin/posters` | アップロード、表示時間、表示/非表示、並び替え（即時反映） |
| 設定 | `/admin/settings` | カメラ選択、「見た」の判定基準、計測中の表示 |

> カメラは `localhost` か `https://` でしか使えません。
> 管理画面とサイネージ画面は **同じパソコン・同じブラウザ** で開いてください（第1段階でクラウド連携して遠隔操作に対応予定）。

## 試し方

1. 管理画面 →「ポスター」→「サンプルを追加」
2. 「サイネージ画面を開く」→ カメラを許可 → `D` キーで計測状況を表示
3. カメラの前で画面を見る（緑枠＝見ている／赤枠＝見ていない）
4. 10秒ごとに保存され、ダッシュボードに反映されます
5. 見た目だけ確認したい場合はダッシュボードの「デモデータを入れて見た目を確認」

## 判定の仕組み

1. MediaPipe Face Landmarker で顔を検出（最大5人, 約10fps）
2. 顔の変換行列から「顔の正面方向」と「顔→カメラ方向」のずれ角（左右・上下）を計算
3. ずれが許容角度（初期値 左右±20°・上下±15°）以内なら「見ている」
4. 0.3秒以上映った人を **通行**、0.5秒以上見続けた人を **注視** として1回だけ数える
5. 見ている間の時間を **注視時間** として、その時表示中のポスターに加算

ロジックは `lib/attention.ts`（ブラウザ非依存）にあり、`npm test` でテストできます。

## カメラ設置のコツ

- モニター上部の中央に、少し下向きで取り付ける
- 逆光（入口のガラス越しの外光）を避ける
- 有効距離の目安は **0.5〜2m**。これより遠い人は検出されにくくなります（第1段階で遠距離向けの検出モデルを検討）
- 設置後、サイネージ画面で `D` →「いまの顔の向きを『画面を見ている』として補正」を押すと、カメラとモニター中央の位置ずれを補正できます

## 既知の制約（第0段階）

- データは端末のブラウザ内のみ。ブラウザのデータ削除で消えます
- 同じ人が一度フレームアウトして戻ると、別の人として数えます（日をまたいだ識別は意図的にしていません）
- 眼球の視線ではなく **顔の向き** で判定しています
- AI でのポスター生成は第2段階で追加予定
